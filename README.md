
# Complaint Management System

## About the Project
The Complaint Management System is a web-based application developed using PHP and MySQL during industrial training at Telecommunications Consultants India Limited (TCIL).

It helps users submit complaints and allows administrators to manage complaints efficiently.

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- XAMPP
- phpMyAdmin

## Main Features

### User Module
- User Registration
- User Login and Logout
- Submit Complaints
- View Submitted Complaints
- Track Complaint Status

### Admin Module
- Admin Login
- View All Complaints
- Update Complaint Status
- Add Employees
- Assign Complaints
- Add Admin Remarks
- Generate Reports
- Export Reports to Excel

### Employee Module
- Employee Login
- View Assigned Complaints
- Update Complaint Status

## Installation and Setup

1. Install XAMPP.
2. Copy the project folder into the `htdocs` directory.
3. Start Apache and MySQL.
4. Open phpMyAdmin.
5. Create a database named `complaint_management`.
6. Import the `complaint_management.sql` file.
7. Open the project in your browser:

   `http://localhost/complaint_management/`

## Project Purpose
The purpose of this project is to provide an organized platform for submitting, tracking and managing complaints.
